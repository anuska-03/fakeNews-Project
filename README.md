# Fake News Detection using Machine Learning

A Machine Learning and Natural Language Processing (NLP) project that detects whether a news article is **Fake** or **Real** based on textual content analysis.

This project demonstrates how machine learning models can be trained on news datasets to classify misinformation effectively.

##  Installation

### 1. Clone the Repository

```bash
git clone https://github.com/anuska-03/fakeNews-Project.git
```

### 2. Navigate to the Project Directory

```bash
cd fakeNews-Project
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

---

## 4. Run Jupyter Notebook:

```bash
jupyter notebook
```
